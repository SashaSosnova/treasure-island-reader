# Остров сокровищ — читай и зарабатывай

Веб-приложение для тестов по книге «Остров сокровищ»
(перевод Николая Чуковского, изд. «Эксмо»).

Сделано по той же схеме, что и читатель «Тома Сойера»: оглавление, тесты, монеты, один подарок в конце книги и режим родителя.

## Как пользоваться на планшете

1. Откройте в Chrome (Android) или Safari (iPad) сайт после публикации.
2. Добавьте на домашний экран:
   - **Android Chrome:** меню ⋮ → «Установить приложение» / «На экран „Домой“»
   - **iPad Safari:** «Поделиться» → «На экран „Домой“»
3. Открывайте ярлык как обычное приложение.

Прогресс и монеты хранятся **в браузере этого планшета**. Не очищайте данные сайта. Перед сменой браузера сделайте бэкап в режиме родителя (`···`).

Ключи хранилища отдельные от «Тома Сойера»: два приложения на одном планшете не перепутают счета.

## Запуск на компьютере

```bash
npm install
npm run dev
```

Откройте http://localhost:5173/

## Что умеет

- оглавление по шести частям романа + итог
- короткий экран главы: факт, слова-лут, «Твой ход»
- тесты по деталям главы (награда 60 / 75 / 90 ₽, финал 150 ₽; потолок книги около 4000 ₽)
- бонус за идеал, серии дней, финал книги и «Твой ход»
- один подарок в конце книги
- счёт, выплаты и режим родителя (PIN)

## Подготовка бумажной книги

В режиме родителя (`···`, PIN по умолчанию `2580`) видно, какой приз готовить к финалу.

Сверьте слова с вашим изданием Эксмо (перевод Н. Чуковского).

## Облако семьи

Тот же Firebase-проект, что у «Тома Сойера», но **другая коллекция**: `treasureIslandFamilies`.

После первого запуска добавьте правило в консоли Firebase (файл `firestore.rules` в репозитории уже содержит оба приложения) и задеплойте правила, иначе семейный код не запишется.
